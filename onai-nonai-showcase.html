🧬 Enzyme — 효소·기질 반응 시뮬레이션

결과물 ↗ GitHub ↗

생물 시간에 배운 효소의 기질 특이성을 3D로 구현했습니다. 효소와 반응물 도형들이 무작위로 떠다니다 모양이 맞는 짝을 만나면 반응해 색이 변하고, 효소는 사라지지 않고 재사용됩니다 — 리스트로 분자들을 관리하고, 중첩 반복문과 절댓값 거리로 충돌을 판정하며, 종류별 반응 횟수를 집계하는 코드입니다.

깃허브에 남은 기록

  • 기질 특이성·효소 재사용이라는 과학 개념을 코드 명세로 번역하는 설계부터 시작했습니다.
  • curve 함수가 점 단위로만 움직이는 한계를 발견하고 도형을 교체하는 우회로를 찾았습니다.
  • 3차원 충돌 판정이 없어 abs 거리 비교를 직접 고안했고, del의 부작용 대신 투명도+remove 조합을 선택했습니다.
  • 반응 횟수가 천 단위로 튀는 print 버그를 조건을 좁혀 해결했습니다.
코딩은 하나만 틀려도 실행되지 않습니다. 같이 머리를 맞대고 고민하는 과정에서 코드가 하나씩 실행될 때의 뿌듯함, 그리고 한 분야를 심화 탐구하며 나를 한층 성장시킬 수 있음이 좋았습니다. — 프로젝트 보고서 성찰에서

📐 몬테카를로로 π를 구하다 — 뷔퐁의 바늘

결과물 ↗ GitHub ↗

바늘을 무작위로 던져 선에 닿는 확률로 π를 추정하는 뷔퐁의 바늘 실험을 3D로 만들었습니다. 스페이스를 누를 때마다 무작위 위치·각도로 바늘이 던져지고, 삼각함수로 교차를 판정해 π 추정값이 실시간 갱신됩니다. 코드 주석에 확률 공식 유도까지 적어 둔, 수학×코딩 융합 프로젝트입니다.

깃허브에 남은 기록

  • if문 10개짜리 거리 계산을 for문 3줄로 리팩터링 — 패턴을 발견해 일반화한 과정이 그대로 남아 있습니다.
  • 연산 우선순위 실수를 괄호로 바로잡고, 카운터 초기값 버그(10→0)를 잡아 확률 집계를 고쳤습니다.
  • 바늘의 회전을 rotate와 라디안 변환으로 구현하고, sin으로 선과의 교차를 판정했습니다.
적분을 아직 배우지 않았지만, 바늘을 던지는 간단한 행동만으로 π를 근사할 수 있다는 것이 신기했습니다. if문 반복을 for문으로 고치는 어려움들을 타개해 나가는 과정에서 성취감을 느꼈습니다. — 프로젝트 보고서 성찰에서

🦠 감염병 확산 시뮬레이션

결과물 ↗ GitHub ↗

바이러스학에 관심 있는 학생들이 감염병 전파를 눈으로 보이게 만든 시뮬레이션입니다. 하얀 공 사이를 돌아다니는 빨간 공이 닿는 공마다 감염시키고, 키를 누르면 "사회적 거리두기"로 확산 속도가 느려집니다.

깃허브에 남은 8일의 기록

  • 두 원의 중심 거리와 반지름 합을 비교하는 수학으로 감염(충돌) 판정을 구현했습니다.
  • 닿지 않아도 감염되던 버그를 리스트를 새로 설계해 잡고, 복잡했던 거리식을 제곱 연산자로 간결하게 다듬었습니다.
  • 선생님 코드를 그대로 쓰지 않고 "모든 빨간 공이 감염시키게" 직접 고쳐 쓰며 8일차까지 감염자 수 카운터에 도전했습니다.
계획할 때는 쉽게 코딩할 수 있을 줄 알았는데 생각보다 너무 어려웠습니다. 그래도 막연했던 아이디어를 직접 구현하며, 시뮬레이션 하나에 고려할 것이 얼마나 많은지 배웠습니다. — 수행 기록(log.md)과 성찰에서

On AI

바이브 코딩 · 데이터 분석 인공지능 기초 — 공공데이터 분석 웹앱 (Streamlit)

🦠 날씨와 독감 환자 수의 상관관계 분석

결과물 ↗ GitHub ↗
계절별 독감 발생률 분석 — 시즌별 ILI 주간 추이

과정

  • 질병관리청 인플루엔자 의사환자(ILI) 분율 12개 시즌 + 기상청 서울 기온 데이터를 직접 수집해 결합했습니다.
  • 역할을 나눠 데이터 찾기·페이지 구상·AI 활용을 분담하고, 계절별 발생 패턴과 기온의 상관관계를 시각화했습니다.
  • "어떤 프롬프트를 입력해야 원하는 답이 나올까"를 반복해서 고민하며 그래프 구현과 오류 해결에 가장 공을 들였습니다.
직접 페이지 주제·내용·기능을 팀원과 함께 구상하며 소통 능력이 성장했고, AI의 답변을 비판적으로 바라보는 관점도 키웠습니다. — 팀원 성찰에서

💧 지역별로 물맛이 다른가?

결과물 ↗ GitHub ↗
수돗물의 화학 성분이 결정하는 물맛과 보건학적 영향

과정

  • 전국 광역시·지자체 상수도사업본부의 공식 수질 성적표를 전수 조사해 경도·pH·이온 함량 데이터로 정량화했습니다.
  • 일별 데이터만 있는 지역을 제외하는 등 "어떤 데이터를 항목으로 쓸지"를 두고 가장 오래 고민했습니다.
  • 화학 성분과 물맛·보건학적 영향을 잇는 멀티페이지 분석 웹앱으로 완성했습니다.
웹앱을 빠르게 만들어내는 것보다, 어떤 데이터를 선택하고 비교할지 결정하는 과정이 훨씬 중요하다는 것을 배웠습니다. — 팀원 성찰에서

에러가 날 때는 답답했지만, 친구들과 협력하고 서로 보완하며 완성하니 혼자였으면 어려웠을 과정에서 더 좋은 결과물이 나왔습니다. — 팀원 성찰에서
