# vibe1-gg — 경기도 정보교사 바이브 코딩 4시간

2026 경기도 정보교사 연수용 웹 교재. 대면 4시간(240분) 과정.

- 교재: `https://greatsong.github.io/vibe1-gg/`
- 기반: 정보교사 1급 정교사 자격연수 4시간판 (`../2026-snui/vibe1/`) — 그 기반은 서울대 평생교육원 15시간판(저장소 `snu-data-2026`)

## 자격연수판과 다른 점

- 연수명 표기를 "2026 경기도 정보교사 연수"로 교체 (제목·eyebrow·footer·갤러리·step4 앱 문구)
- 인트로 지도를 **경기도 확대판**으로 변경 — `board.html`은 경기도 시군구(코드 31##)만 그리고, `map.html`은 경기도 중·고만 검색된다
- 갤러리 Supabase 표를 `vibe1gg_apps` 등으로 분리 (`gallery/schema.sql` 재실행 필요)
- 인트로 백엔드 `API_URL`은 비워 둠 — 경기도 연수 전용 새 시트로 배포 후 채울 것
- STEP 1~4 본문(전국 고령화 지도 등 실습 소재)은 검증된 자격연수판 그대로

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 허브 — 오늘의 흐름, 단계별 진입 |
| `map.html` | **인트로 · 참가자 폰** — 경기도 학교 검색 후 전송 |
| `board.html` | **인트로 · 앞 화면** — 실시간 경기도 지도 |
| `Code.gs` | 인트로 백엔드 (Google Apps Script) |
| `prep.html` | 준비물 — 계정 3개 |
| `step1.html` | 20~80분 · 첫 배포 (인구·고령화 지도) |
| `step2.html` | 90~130분 · 키 다루기 (KOBIS) |
| `step3.html` | 130~165분 · 나만의 AI 채팅앱 |
| `step4.html` | 175~210분 · 합치기 (멀티페이지) |
| `extra.html` | 심화 자료 (DB · 오늘 다루지 않은 것 · 자동화) |
| `glossary.html` | 용어 사전 |

교재는 **한 벌**이다. 독자가 교사이므로 호칭은 "선생님", 배지는 `선생님용`. 강사용 별책은 만들지 않았다.

15시간판의 `gate.js`·`release.js`(일차 순차 공개)는 가져오지 않았다. 하루 완결이라 잠글 이유가 없다.

## 연수 전 준비 (강사)

1. **계정 3개 사전 안내** — 연수 공지에 깃허브·스트림릿 클라우드·AI 서비스 가입을 넣는다. 현장에서 만들면 STEP 1이 무너진다.
2. **인트로 백엔드 배포** — 기존 자격연수 스프레드시트의 Apps Script에 이 교재의 `Code.gs`를 붙여넣고(덮어쓰기) **배포 · '새 배포'** 로 웹 앱(액세스: 모든 사용자) URL을 새로 만든 뒤, 그 URL을 `map.html`과 `board.html`의 `API_URL`에 넣는다. 데이터는 같은 파일의 `mapgg` 시트(탭)에 따로 쌓여 자격연수 데이터(`map4`)와 섞이지 않고, 자격연수판 URL은 배포 버전이 고정돼 있어 영향이 없다. 현재 `API_URL`은 비어 있어 테스트 모드로 뜬다.
3. **갤러리 표 생성** — Supabase SQL Editor에서 `gallery/schema.sql`을 1회 실행한다 (`vibe1gg_` 표가 새로 생긴다).
4. **키 준비** — KOBIS는 전원 발급이 원칙이되 예비 키를 준비한다. AI 채팅앱 키는 강사가 제공한다.
5. **완성본 저장소** — 각 단계의 완성 코드를 공개 저장소에 올려 fallback 링크로 건다.
6. **데이터 점검** — 연수 전날 원본 저장소의 `scripts/validate_data.py` 실행.
7. **와이파이** — 대면이라 동시 접속 대역을 확인한다. 스트림릿 빌드가 동시에 몰리면 느려진다.
